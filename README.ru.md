# ZCode Session Viewer

**Локальный веб-инструмент без зависимостей** для просмотра, поиска и управления всей историей сессий [ZCode](https://z.ai), включая архивные.

> Десктопный ZCode показывает список сессий только текущего проекта и плохо подходит для глубокого поиска по прошлым разговорам. Этот инструмент читает локальные базы ZCode напрямую и прямо в браузере даёт просмотр по всем проектам, полнотекстовый поиск, управление архивом и поиск внутри сессии.

## Возможности

- **Полный список сессий**: объединяет индекс десктоп-интерфейса и базу сессий — видны все сессии всех проектов; бейджи: в архиве / закреплено / fork / только CLI (внутренние сессии субагентов)
- **Два режима списка**: `🗂 по проектам` (группы сворачиваются, «свернуть всё» / «развернуть всё», состояние запоминается) и `⏱ по времени` (по возрастанию / убыванию)
- **Управление архивом**: архивация / разархивация в один клик — пишется то же поле, которое читает интерфейс ZCode, поэтому оба остаются синхронными
- **Глобальный поиск**: название / проект / ID сессии / полнотекстовый поиск (SQLite LIKE за миллисекунды)
- **Поиск внутри сессии**: подсветка совпадений, счётчик, циклическое перемещение ▲▼ / Enter, автоматическое раскрытие свёрнутых блоков инструментов и размышлений
- **Чтение в стиле ZCode**: рендеринг markdown (заголовки / блоки кода / таблицы / списки), строки вызовов инструментов (цветной статус + краткие аргументы, раскрытие показывает полный ввод/вывод), сворачиваемые размышления, приглушённые служебные вставки
- **Тёмная / светлая тема · мультиязычный интерфейс**: переключение 🌙/☀️; интерфейс на 中文 (по умолчанию), English, Русский; язык подписей в экспортируемом Markdown следует за языком интерфейса; все настройки запоминаются локально
- **Экспорт сессии**: экспорт одной сессии в один клик, в имени файла — метка формата (`название_md.md` / `название_json.json` / `название_jsonl.jsonl` / `название_raw.jsonl`) — `Markdown` (для чтения, вызовы инструментов/размышления в сворачиваемых блоках), `JSON` (полные структурированные данные), `JSONL` (одно сообщение на строку, удобно для потоковой обработки), `RAW` (исходные записи ZCode — строки session/message/part как есть, без фильтрации и обрезки)
- **Настраиваемая раскладка**: перетаскиванием меняется ширина панели сессий (запоминается)
- **Копирование ID сессии в один клик**: вставьте в ZCode как `#sess_xxx`, чтобы восстановить контекст
- Открытая сессия подсвечивается в списке и автоматически прокручивается в поле зрения

## Быстрый старт

```bash
python src/viewer.py
# автоматически открывает http://127.0.0.1:8787
```

Требуется Python 3.8+ (только стандартная библиотека — никаких сторонних пакетов, ничего собирать и устанавливать не нужно).

```bash
python src/viewer.py --port 9000        # другой порт
python src/viewer.py --no-open          # не открывать браузер автоматически
python src/viewer.py --db-main PATH --db-tasks PATH   # пути к базам вручную
```

## Источники данных и приватность

Инструмент работает **полностью локально** — не делает внешних сетевых запросов и ничего не отправляет.

| База (определяется автоматически, см. ниже) | Назначение | Доступ |
| --- | --- | --- |
| `<каталог>/cli/db/db.sqlite` | содержимое сессий (message / part) | только чтение |
| `<каталог>/v2/tasks-index.sqlite` | индекс списка сессий (архив/закреплено/проект) | чтение + запись флага архива |

Единственная операция записи — архивация / разархивация (`UPDATE tasks SET archived = ...`) в то же поле, которое читает интерфейс ZCode, поэтому изменения появятся в приложении ZCode после повторного открытия списка сессий.

**Автоопределение каталога данных** (по порядку): переменная окружения `ZCODE_HOME` → `~/.zcode` (раскладка по умолчанию на всех платформах) → `~/.config/zcode` → `~/Library/Application Support/ZCode` (резерв для macOS). Если ничего не найдено, **на странице появится окно настройки** — укажите каталог данных (или в расширенном режиме пути к двум базам по отдельности) и сохраните. Выбор запоминается в `~/.zcode-session-viewer.json` и больше не спрашивается; кнопка ⚙ в шапке открывает окно снова. Аргументы командной строки `--db-main` / `--db-tasks` имеют наивысший приоритет.

### Поддержка платформ

Код использует только стандартную библиотеку Python (pathlib / sqlite3 / http.server) без платформозависимых API, поэтому одинаково работает на Windows / macOS / Linux. Проверено на Windows; macOS и Linux должны работать «из коробки» (та же раскладка домашнего каталога) — если ваш ZCode хранит данные в другом месте, просто укажите пути при запуске. Сообщения об ошибках с этих платформ приветствуются в issues.

## Известные ограничения

- При одновременной записи одной строки с ZCode архивация ждёт до 3 с (блокировка на уровне базы); при сбое возвращается ошибка, данные не повреждаются
- Приложение ZCode кэширует список сессий в памяти: после архивации здесь заново откройте список в ZCode, чтобы увидеть изменения
- Сессии «только CLI» отсутствуют в индексе интерфейса ZCode, поэтому кнопки архивации у них нет

Он читает только базы сессий, которые ZCode уже хранит на **вашем собственном компьютере**, и выполняет единственную запись флага архива в индекс задач.
